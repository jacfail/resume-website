LabVIEW FESTO Process Control Training Bench

This project utilized a FESTO Process Control Training Bench and LabVIEW to regulate flow, pressure, temperature, and vibration in order to achieve a desired tank level. A PID controller monitored system feedback and applied corrections in real time.

Flow was controlled by adjusting motor speed based on feedback from a paddle wheel flow transmitter, while pressure was regulated by monitoring a pressure transmitter. Since physical sensors for temperature and vibration were not available on the bench, both variables were simulated mathematically. Temperature was modeled using an additional PID controller and a provided equation derived from the tank volume, water density, and specific heat of water. Vibration was calculated directly from the flow rate using a provided formula, requiring no additional PID controller.

A PID controller was utilized to monitor the feedback from all these variables and make the necessary corrections to achieve the desired tank level. The design and control of the system was all implemented in LabVIEW.

Technical Highlights
  • LabVIEW programming for real-time process control
  • PID controller design and tuning for multiple variables
  • Sensor integration (paddle wheel flow transmitter, pressure transmitter)
  • Motor speed control for flow regulation
  • Physics-based simulation of temperature and vibration variables
  • Data-driven feedback loop implementation and correction
